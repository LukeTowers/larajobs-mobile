Speaker Notes:
This is the Livewire way. I define a public property $query. I bind it to the input with wire:model.live. That’s it. I don't need an event listener. I don't need a fetch request. When the user types, Livewire automatically updates the property on the server. My PHP class is the frontend state. It's just PHP!
