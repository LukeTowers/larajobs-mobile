Title: The jQuery Way
Layout: Code Block
Body:
$('#search').on('keyup', function() {
    let query = $(this).val();
    $.get('/search', { q: query }, function(html) {
        $('#results').html(html);
    });
});

Speaker Notes:
First, we had the jQuery way. We’d listen for a keyup, fire an AJAX request, get a chunk of HTML back, and smash it into the DOM. It was fast. It worked. But let’s be honest... it was spaghetti code. Managing state was a nightmare.
